# F1TV-DL-WebUI

Self-hosted web UI for f1tv-dl with F1 TV login, credential settings, session browsing, download queue, and MP4 downloads to a tablet.

## Implementation handoff

See [DOCS/IMPLEMENTATION-SPEC.md](DOCS/IMPLEMENTATION-SPEC.md) for the complete requirements, architecture, upstream integration findings, security requirements, deployment instructions to implement, and acceptance criteria.

Current status: specification committed; application implementation and live F1 TV compatibility verification are pending. No application has been deployed.
